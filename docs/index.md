# Welcome to Aurora-Provider Documentation

Aurora-Provider is a local, self-hosted, OpenAI-compatible LLM router that multiplexes requests across multiple free AI providers, manages API key rotation, routes traffic through SOCKS5 proxies (Beta), and provides a full-featured analytics dashboard.

## Table of Contents

- **[Architecture](architecture.md)** — Learn how the request lifecycle, SOCKS5 proxy pool (Beta), and key rotation work under the hood.
- **[Dashboard](dashboard.md)** — Guide to the System Status, Config Editor, Logs, Proxy Pool (Beta), and Usage Analytics tabs.
- **[API Reference](api-reference.md)** — Complete endpoint specifications, headers, parameters, and OpenAI SDK integration guides.
- **[Providers Guide](providers-guide.md)** — Step-by-step instructions on signing up and obtaining free-tier API keys for all 11+ supported providers.
