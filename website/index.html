Designed for Zero-Downtime AI

A high-performance gateway that wraps your local and remote LLM providers with multiple defense layers.

🔌

OpenAI Compatibility

Drop-in replacement for any OpenAI SDK. Just point your client library base URL to your Aurora-Provider host. Zero code changes required.

🛡️

Dynamic Proxy Shielding

Scrapes and tests hundreds of SOCKS5 proxies in the background. Routes traffic through validated proxies to mask your IP and prevent origin blocking.

🔄

Seamless Key Rotation

Define multiple API keys per provider. Aurora automatically rotates to the next key on 429 Rate Limits, setting cooling periods automatically.

🎭

Auras (Routing Profiles)

Map application tasks to logical profiles. A single endpoint `aurora-provider/coder` can fall back from Anthropic to OpenAI, then Gemini, and finally Groq.

⚡

Bun + Hono Performance

Engineered with Bun runtime and Hono framework. Consumes less than 30MB of RAM and routes requests with near-zero latency overhead.

📊

SQLite Analytics

Maintains robust logging and speed statistics with WAL-mode SQLite database optimizations. Search, filter, and audit usage logs in real time.

Get Started in 60 Seconds

Start routing LLM requests with automatic resilience and proxy shielding locally.

Clone the repository and install dependencies using Bun.

git clone https://github.com/ahmed-zhran/aurora-provider.git
cd aurora-provider
bun install

Rename the example keys file and configure your LLM provider API keys.

cp vault/keys.example.json vault/keys.json
nano vault/keys.json

Boot up the router server. Background SOCKS5 proxy harvesting starts automatically.

bun run src/server.js

Direct any OpenAI-compatible client (e.g. Python) to your local server.

from openai import OpenAI

client = OpenAI(
    api_key="any-string-works",
    base_url="http://127.0.0.1:8550/v1"
)

# Route request through the "coder" fallback chain
response = client.chat.completions.create(
    model="aurora-provider/coder",
    messages=[{"role": "user", "content": "Hello Aurora"}]
)

print(response.choices[0].message.content)
